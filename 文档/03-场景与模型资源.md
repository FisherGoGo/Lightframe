# 03 场景与模型资源

[返回总览](00-项目总览与开发顺序.md)

Scene 描述场景里有什么，Renderer 决定怎样绘制。模型加载器把资源文件转换为项目能使用的网格、材质和纹理。

阶段安排：A 建立几何实验台，C 加入基础光照，D 布置景深实验，E 加入确定性运动。模型导入是加分项，目标版本可以完全使用几何体与简单纹理完成三个实验。

## 1. 需要实现什么

| 功能 | 最小实现 |
|---|---|
| 物体摆放 | 每个对象有位置、旋转、缩放和模型矩阵 |
| 测试场景 | 地面、不同深度的几何体、明暗区域、高亮小物体 |
| 灯光 | 先实现一个方向光或点光源，以及基础材质 |
| 正式场景（选做） | 导入一个现成静态模型或房间 |
| 动画 | 小球或叶片的位置、角度由指定时间计算 |
| 场景切换与复位 | 测试场景和正式场景共用相机与成像流程 |

## 2. 先搭一个实验台

用立方体和平面组成场景，每个对象单独计算：

```text
model = translation × rotation × scale
```

在 GLM 的常见列向量约定下，顶点先经过缩放，再旋转，再平移。顶点着色器使用 `projection * view * model * position`。

放置近、中、远三个物体，左右错开，增加带细节的纹理和背景亮点。若想验证 2、5、10 m 测距，应按初始相机的 front 方向布置对应轴向距离，不能仅给物体填写某个世界 Z 值。

先用基本环境项、漫反射和高光表现明暗。场景亮度在线性空间计算；高亮小物体可以输出大于 1 的自发光颜色，帮助观察散景。自发光表面不自动成为照亮周围的光源。

三个实验可共用场景，但应保存独立预设。测距使用轴向 2、5、10 m 的物体；景深演示另设近主体与远背景，例如 85 mm、f/2、对焦 1 m，主体位于 1 m、背景位于 5 m。运动实验让小球横穿画面中部，保证长短快门区间内均不出画。几何、纹理、运动速度和灯光一经用于验收就固定，避免参数对比时场景也发生变化。

## 3. 怎样导入现成模型

建议流程：

1. 用 Assimp 读取文件，检查导入错误。
2. 遍历节点，累积父子节点变换。
3. 为每个网格读取位置、法线、UV、索引，创建 VAO/VBO/EBO。
4. 读取支持的材质和贴图，纹理路径相对模型目录解析。
5. 将节点累计变换与场景对象变换组合后绘制。
6. 校准整体尺度、朝向和位置，再加入相机和灯光。

节点最终变换为 `parent * local`。第一版可以在加载时把变换烘焙到顶点，也可以保存到绘制阶段；选择一种，避免应用两次。缩放后的法线使用逆转置法线矩阵。

先加载一个小物件，再加载整个房间。教程中的 [Model](https://learnopengl.com/Model-Loading/Model) 提供遍历与网格组织思路；项目仍需明确处理所选资产的节点变换和材质。

材质先支持基础颜色贴图和有限的光照参数。缺贴图时给默认材质并报告路径。颜色贴图需要按 sRGB 转为线性；法线、粗糙度等数据贴图不做 sRGB 解码。不要让整个场景是否可运行依赖复杂 PBR、透明玻璃或骨骼动画。

## 4. 动画怎样支持拍照

不要每帧执行 `position += velocity * dt` 作为唯一状态来源。拍照要能查询任意时刻的物体位置：

```cpp
glm::vec3 positionAt(double time) {
    return startPosition + velocity * float(time);
}
float angleAt(double time) {
    return initialAngle + angularVelocity * float(time);
}
```

以上适用于短时间匀速演示。正式运行可加明确的周期运动或时间原点，避免无限远移。Scene 的 `evaluateAt(time)` 根据同一场景配置生成物体矩阵；相同 time 得到相同结果。

这样 Capture 能在快门区间内重复绘制多个状态，并且用相同起始时间做参数对比。随机动画若存在，也必须固定种子；首版无需加入。

## 5. 资源与复位

- 记录作者、来源、许可和必要署名，保留贴图与模型一起分发。
- 模型尺寸统一为米，否则景深计算会失真。
- 复位恢复场景时间、对象设置和实验机位；资源无需重新加载。
- 测试场景长期保留，正式场景出问题时用它区分算法错误和资产错误。

## 6. 完成条件

- 物体可以独立变换，遮挡关系与绘制顺序无关。
- 选做模型导入时，正式模型的尺寸、贴图和子节点位置正确；缺失资产不影响几何实验台运行。
- 相同动画时间得到相同物体位置。
- 场景可切换，资源来源有记录，缺失文件有明确提示。
