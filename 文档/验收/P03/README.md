## 用户手动检查

1. 用 VS 打开 `Photograph.slnx`，选择 x64 Debug 并按 F5。左侧显示焦距面板，右侧显示完整 3:2 取景画面，默认 50 mm。
2. 点击 **Reset experiment A (24 mm)**，确认机位为 `(0, 1.2, 3)` m。依次点击 24/35/50/85 mm，观察主体逐渐放大、取景范围缩小，机位读数保持不变。
3. 拖动焦距滑块；Ctrl+单击滑块输入精确值。将鼠标移到取景器后滚轮变焦，确认焦距在 24～85 mm 范围内、机位保持不变。面板及留边上的滚轮不应触发取景变焦。
4. 单击取景器空白退出面板键盘焦点，用 WASD/QE 移动，右键转向。R / **Reset pose** 只恢复机位并结束观察，保留焦距；**Reset focal length** 只恢复 50 mm，保留机位；实验 A 按钮同时恢复机位和 24 mm。
5. 固定机位切换 24/85 mm 后，移动相机使主体大小接近，比较主体与远景关系，区分变焦和移动的透视变化。
6. 拖动/编辑焦距时按 WASD/QE/R、在面板按右键，确认不误触移动、机位复位或观察；右键观察期间滚轮不改变焦距，松开后可继续操作面板，首次观察无跳动。
7. 缩放成宽/竖窗口，确认完整构图和物体比例保持，面板与留边不启动机位操作；失焦、最小化与恢复后没有持续移动或观察。高 DPI 显示器上确认鼠标命中和显示区域一致。
8. UI 未占用键盘时 Esc 退出；精确数值编辑时 Esc 先取消编辑。窗口关闭按钮应正常退出。
