- 本机环境沿用 [P00/P01](../P00-P01/README.md)：VS 2026、v145、C++17、GLFW 3.4、GLM 1.0.1；NVIDIA GeForce RTX 4070 Laptop GPU / OpenGL 3.3.0 / NVIDIA 610.74。
- x64/Win32 × Debug/Release 均 Rebuild，通过且为 0 警告、0 错误。四种配置从仓库根目录启动 `--smoke-test`，完整场景中心的橙色主体和深度读回均通过。
- 独立 CPU 检查通过：初始观察矩阵匹配 P01；30/144 FPS 各移动一秒均为 2.5 m；斜向移动仍为 2.5 m/s；向右转向与俯仰限幅正确；复位位置及方向一致；移动转向不改变投影；五个实例及主体/地面接触关系正确。
- 实际 GLFW 窗口自动操作通过：W/A/S/D/Q/E 各改变构图；R 恢复原位置和方向；右键首次进入不跳动、拖动改变方向、释放后鼠标移动不转向；按住 W 和右键时将焦点交给另一顶层窗口，相机停止，恢复焦点后不持续移动或转向。
- 1200×600 宽窗、600×900 竖窗与 900×600 恢复窗口继续绘制；缩放后恢复及最小化后恢复与初始画面一致；Esc 返回 0。

比较使用客户区内部 RGB 像素的 SHA256，排除外围 10 px，因为 Windows 圆角会混入桌面像素。保存的截图仍为完整客户区。窗口测试经 Win32 消息和真实焦点切换进入 GLFW 回调，未执行人工操作验收。初次桌面测试遇到沙箱截图句柄不可用；之后在可访问交互桌面的执行环境完成。窗口首帧可能暂被桌面遮挡，脚本等待并检查中心颜色后再取基准。

## 复验

从仓库根目录使用 PowerShell 7（`pwsh`）运行；默认 `recheck-*` 避免覆盖本轮证据。

```powershell
& ./文档/验收/P02/build.ps1
& ./文档/验收/P02/verify-camera.ps1
& ./文档/验收/P02/verify-window.ps1
```

本轮构建分步运行 `build.ps1 -Stage p02 -Platforms x64 -Configurations Debug`、同命令的 Release 配置及 `build.ps1 -Stage p02 -Platforms Win32`；CPU 与窗口脚本均使用 `-Stage p02`。CPU 脚本通过 vswhere/vcvars64 编译独立检查程序，输出到忽略的 `Photograph/bin/camera-tests/`；构建脚本只对 MSBuild 子进程的环境变量去重，不修改系统配置。

窗口脚本需要可访问的交互桌面，会短暂调整窗口与焦点，仅截取项目客户区；桌面需容纳最大 1200×600 或 600×900 客户区、边框和 100 px 起始偏移，焦点辅助窗口位于 `(1100,100)`。复验期间请避免其他窗口遮挡测试窗口。

## 范围与限制

P02 本机验收完成；课程演示设备、其他显卡及人工操作尚未验证。当前允许自由飞行和穿过物体，颜色由各面固定深浅与实例乘子决定，无真实光照、模型导入或摄影参数 UI。固定 45° 投影由 P03 的焦距与传感器设置替换。三个远景中心 Z 为 -3/-6/-9 m，仅作空间参照，不表示相对倾斜机位的轴向距离。

## 同日调整：逐帧轮询转向

用户要求沿用 `CUC_CG/07_摄像机_10.12/Work2` 的转向形式。当前实现取消鼠标坐标回调，App 在每帧输入处理中用 `glfwGetCursorPos()` 读取位置，计算 `dx=x-lastX`、`dy=lastY-y`，更新基准后传给 Camera；先转向，再按更新后的方向移动。进入右键捕获后立即读取基准，松开、失焦和 R 复位仍结束观察。Camera 直接累加 yaw/pitch，保留 ±89° 俯仰限幅和用户调整的 0.05°/坐标单位灵敏度，不给鼠标位移乘 `dt`。

四种配置 Rebuild 与绘制自检均通过，0 警告、0 错误；独立 CPU 检查全部通过，90° 转向检查输入调整为 1800 个坐标单位。完整窗口复验通过移动、复位、右键进入/转向/释放、失焦恢复、缩放、最小化恢复与 Esc。Debug/Release 均已重新构建。

最新证据见 CPU 检查（`p02-polling-camera.log`，仅本地）、窗口检查（`p02-polling-window.log`，仅本地）、源码清单（`p02-polling-source-sha256.log`，仅本地） 与 `p02-polling-build-*.log` / `p02-polling-smoke-*.log`。`p02-*` 的原始记录与清单保留为首次版本证据。
