# 05 成像与后处理

[返回总览](00-项目总览与开发顺序.md)

这一部分是摄影模拟的主要算法：把摄影参数变成亮度、清晰范围和噪声变化。建议由 `PostProcess` 组织各轮绘制，GLSL 着色器执行每像素计算。

阶段安排：C 完成曝光和显示转换；D 完成深度、CoC 与基础景深；F 加入简化噪声。前后景分层、覆盖率扩展和半分辨率上采样均为加分项，不作为基础景深的完成条件。

## 1. 功能与实现位置

| 功能 | 输入 | 输出 / 方法 |
|---|---|---|
| 曝光 | 光圈、快门、ISO、线性颜色 | 相对曝光倍率乘颜色 |
| 深度重建 | 深度纹理、近远裁剪距离 | 正轴向距离，用于对焦和景深 |
| 散焦圈 | 距离、焦距、光圈、对焦距离 | 每像素应模糊多大 |
| 景深 | 颜色、深度、散焦圈 | 深度感知的圆盘采样与合成 |
| 噪声 | 曝光结果、ISO、像素位置、种子 | 简化传感器噪声 |
| 显示转换 | 线性 HDR 结果 | 色调映射并编码成显示颜色 |

快门拖影需要多个时刻的场景图像，由 Capture 控制，不是在这里对单张照片横向模糊。

## 2. 先实现曝光

以 f/4、1/125 s、ISO 100 为基准：

```text
M = (shutterSeconds / (1/125))
  × (4 / apertureFNumber)²
  × (iso / 100)
exposedColor = linearColor × M
```

这是相对曝光模型，不做真实照度标定。初期在 CPU 算倍率，以 uniform 传入着色器。快门乘 2、ISO 乘 2，都应使色调映射前的亮度乘 2；f 值乘 √2 应使亮度减半。

第一版可使用固定的 Reinhard 色调映射 `mapped = color / (1 + color)`。之后执行一次线性到 sRGB 编码；若暂用 `pow(mapped, 1/2.2)`，应标为近似，且确保输出路径没有再次编码。精确 sRGB 编码可写为每通道分段函数：

```text
c <= 0.0031308: 12.92 × c
其他: 1.055 × c^(1/2.4) - 0.055
```

色调映射设置固定，不自动补偿参数变化。曝光验证应比较线性结果，而不是要求 PNG 像素严格翻倍。浮点颜色和色调映射的区别见 [LearnOpenGL HDR](https://learnopengl.com/Advanced-Lighting/HDR)。

## 3. 再实现深度重建

下面公式仅适用于本项目约定的常规 OpenGL 透视投影与默认深度范围：

```text
ndcZ = 2 × depth - 1
zMeters = (2 × near × far)
        / (far + near - ndcZ × (far - near))
```

`zMeters` 为相机空间沿光轴的正距离，不是相机到物体的欧氏距离。near/far 必须和渲染该深度纹理时的投影一致。首版背景深度清除为 1，无几何体的像素不参与点击测距；景深可选择保持背景不变并记录这个处理。

先显示归一化深度调试图和点击数值，用已知轴向距离的物体验证，再写模糊。远裁剪距离不宜无意义地拉得很大，否则近距离深度精度下降。

## 4. 如何计算散焦圈

使用以下薄透镜近似，所有长度先转成 mm：

```text
f = focalLengthMm
s = focusDistanceM × 1000
z = zMeters × 1000
N = apertureFNumber

cSigned = f² × (z - s) / (N × z × (s - f))
signedRadiusPixels = 0.5 × cSigned / sensorHeightMm × imageHeight
radiusPixels = abs(signedRadiusPixels)
```

要求 `s > f`，并避免 z 接近零。这里 c 表示传感器上的散焦圈直径，像素半径要乘 0.5。本指南规定负值代表前景、正值代表背景，方便后续分层。

先做 CoC 调试图：对焦距离附近应接近零，远离对焦层时数值增大。50 mm、f/4、对焦 5 m、物体轴向距离 10 m 时，散焦圈直径约 0.063 mm，在 600 像素高的照片上半径约 0.79 px。这也提醒我们，合理物理参数下虚化可能很轻，不能为了看起来明显就悄悄扩大公式结果。

## 5. 景深怎样从简单版本逐步实现

第一轮可以用中心像素的 radius 决定采样范围，圆盘上取 16～32 个点，用 `offsetPixels / imageSize` 转成 UV 偏移，平均采样颜色。radius 接近零时直接取原始颜色。

这只是调通算法的版本：直接平均会让前景颜色渗入背景，也难以表现前景向外扩散的虚化。目标版本增加下面第 1 项的基础跨层权重处理，并保留边缘误差说明；第 2～4 项属于后续加分改进：

1. 同时采样邻居的深度与 CoC，给不合适的跨层样本降低权重；权重和为零时返回原图。
2. 区分前景和背景模糊，前景层还保存覆盖率，必要时扩展前景 CoC 范围。
3. 分别得到前景与背景模糊结果，用覆盖率和清晰层合成。
4. 对半分辨率实现使用深度感知上采样，避免在物体边缘出现光晕。

不要用一个通用深度阈值宣称完全解决了遮挡。单层颜色和深度没有被挡住的背景信息，仍会有边缘近似误差。首版可先完成基础版本，报告限制，再根据时间改进。

采样最大半径、样本数是性能控制，需要记录。当限制半径导致模糊小于理论值时，应在算法说明里指出。物理上明显的演示可通过靠近主体、提高焦距、打开光圈和拉开背景距离来安排。

初始质量设置可固定为全分辨率、24 个圆盘样本、最大半径 24 px。先以此建立截图和耗时基线，再决定是否调整；这些是候选预算，不是已验证性能。CoC 数值验收读取未截断结果，照片说明记录实际半径限制。基础版本验收关注焦平面、光圈变化和可解释的模糊趋势，不要求修复单层深度无法恢复的遮挡信息。

## 6. 最后加入简化噪声

首版采用可控视觉近似，明确不代表真实传感器。一个容易实现的起点是对曝光后的线性颜色加零均值噪声：

```text
sigma = baseStrength × sqrt(ISO / 100)
noisy = max(exposedColor + sigma × randomNormal(pixel, seed), 0)
```

`baseStrength` 是明确记录的模拟强度，先用很小的值。用像素整数坐标、固定种子和通道编号生成可复现随机数；需要近似高斯分布时可由两个均匀随机数转换，避免对零取对数。

这一近似在“快门缩短、ISO 提高、输出亮度相近”的实验中能表现更明显噪声，但不能据此把 ISO 当成真实噪声的唯一原因。后续可扩展为光子散粒噪声与读出噪声，首版无需实现。

噪声只在时间样本平均之后加入一次；不在每个样本里加入，否则增加样本数会改变最终噪声强度。预览种子先保持固定，拍照种子随照片记录。

## 7. 完成条件

- 等曝光参数组合得到相近线性亮度。
- 深度读数与已知距离相符，背景不误触发对焦。
- 对焦层清晰，大光圈让离焦区域模糊更强。
- 在补偿曝光后仍能观察到景深变化。
- 固定种子可以复现噪声，改变时间采样数不明显改变噪声设定。
- 所有效果可单独关闭；照片和预览共用成像代码。

建议实现顺序：曝光 → 深度 → CoC 调试图 → 基础景深及基础跨层权重 → 配合 Capture 完成时间采样 → 噪声。高级边缘改善在目标版本稳定后再做。
