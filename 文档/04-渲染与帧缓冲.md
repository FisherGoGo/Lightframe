# 04 渲染与帧缓冲

[返回总览](00-项目总览与开发顺序.md)

Renderer 把 Scene 和 Camera 转为图像。FBO 是渲染目标的组织方式，纹理保存中间结果；后处理读取这些结果生成照片。

阶段安排：C 只需 sceneColor、sceneDepth、photoColor 和转显通道，D 增加 CoC 与景深目标，E 增加独立累加目标。每添加一种目标都先验证完整性和调试显示，不提前建立全部资源。

## 1. 需要实现什么

- 编译和管理场景着色器、全屏着色器。
- 根据物体、材质、灯光、观察矩阵与投影矩阵绘制场景。
- 创建可采样的颜色纹理和深度纹理。
- 把离屏结果显示到窗口，并提供给后处理和拍照模块。
- 管理目标尺寸、viewport、深度测试、混合状态和资源释放。

## 2. 场景怎样画出来

场景顶点着色器计算裁剪空间位置，传出 UV、世界位置和法线；片元着色器根据材质与灯光输出线性颜色。

```glsl
gl_Position = projection * view * model * vec4(aPosition, 1.0);
```

每帧设置相机矩阵和灯光；每个对象设置 model 和材质后绘制。开启深度测试并清除颜色与深度。先直接画到窗口，结果正确后再迁移到 FBO。

## 3. 建议准备哪些渲染目标

| 目标 | 内容 | 建议格式 |
|---|---|---|
| sceneColor | 未曝光的线性场景颜色 | RGBA16F |
| sceneDepth | 场景深度 | DEPTH_COMPONENT24 深度纹理 |
| coc | 带符号散焦圈半径 | R16F，后续加入 |
| dofColor | 景深处理后的线性颜色 | RGBA16F |
| accumulation A/B | 时间样本求和或平均 | RGBA32F，后续加入 |
| photoColor | 编码后的最终照片 | RGBA8 |

格式是初始选择，实际创建后应检查 framebuffer 完整性。深度附件必须是纹理，后处理才能采样；仅用于深度测试的 renderbuffer 无法直接作为普通纹理读取。参考 [LearnOpenGL Framebuffers](https://learnopengl.com/Advanced-OpenGL/Framebuffers)。

第一版只创建 sceneColor、sceneDepth 和一个转显通道，之后按功能添加目标。深度纹理设置最近邻采样、关闭深度比较模式，用它读取原始深度；颜色纹理通常使用线性过滤，边界采用 clamp-to-edge。

## 4. FBO 怎么创建与使用

创建顺序：生成 FBO → 为纹理分配存储 → 把颜色和深度纹理附加到 FBO → 设置颜色输出附件 → 检查 `glCheckFramebufferStatus`。

渲染场景：

```text
绑定 scene FBO
→ viewport 设为照片尺寸
→ 开启深度测试，关闭不需要的混合
→ 清除颜色和深度
→ 绘制所有场景对象
```

后处理：

```text
绑定另一个输出 FBO
→ viewport 设为该目标尺寸
→ 关闭深度测试和不需要的混合
→ 绑定输入纹理及 uniform
→ 绘制覆盖目标的全屏三角形或四边形
```

一轮这样的绘制叫一个 Pass。每个 Pass 显式设定依赖的状态，避免上一轮设置影响下一轮。

不能把某纹理当作普通输入采样，同时向同一纹理绘制。多轮处理使用不同输入输出，必要时准备 A/B 两套目标交替。

## 5. HDR 与颜色处理怎么衔接

RGBA16F 保留大于 1 的亮度；曝光和景深都在这个阶段计算，随后进行色调映射。相关概念参考 [LearnOpenGL HDR](https://learnopengl.com/Advanced-Lighting/HDR)。

本项目首版建议：最终着色器完成显示编码，写入普通 RGBA8 photoColor，窗口呈现时原样复制，并关闭再次执行 sRGB 编码的状态。若改用硬件 sRGB 输出，需要连同导出路径一起设计，保证不重复编码。

## 6. 照片怎样显示到窗口

固定照片比例 3:2，以窗口可用区域为边界计算最大内接矩形，其他区域留边。UI 或呈现层保存这个实际矩形，点击对焦使用同一矩形换算坐标。

不把窗口宽高比直接传给照片的投影矩阵，否则窗口变宽就会改变摄影构图。首版固定照片像素尺寸，后续再支持重建所有相关目标。

拍照完成后的结果与实时预览必须有明确的资源归属。可以在 Finalizing 后立即读回照片像素并交给保存步骤；若延后读回或展示上一次照片，则保留独立照片纹理。预览下一次绘制不能覆盖尚未读取的最终照片。

## 7. 完成条件

- 原样转显与直接绘制的构图一致，无倒置或拉伸。
- 深度调试图能分辨远近，背景有可识别的清除值。
- 灰度测试只影响场景，不影响 UI。
- 目标创建失败有日志，纹理读写没有相互反馈。
- 放大曝光后原本高亮处仍有层次，说明未提前截断 HDR。
